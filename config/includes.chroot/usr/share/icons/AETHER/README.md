# AETHER OS Official Icon Pack

Original, individually generated SVG icon assets for the AETHER OS desktop concept.

## Contents
- 152 individually named full-color SVG icons across apps, devices, network, folders, MIME types, system, actions and status.
- 8 symbolic SVG variants.
- `index.theme` Freedesktop-style theme metadata.
- `ICON-INVENTORY.csv` complete asset list.
- `PREVIEW.html` local gallery for browsing icons.

## Visual identity
Original geometric AETHER-inspired forms, purple/blue/cyan gradients, rounded shapes and consistent 64x64 viewBox. The assets intentionally use generic application symbols rather than copying proprietary Apple branding or third-party app logos.

## Use
Copy the `aether` directory and `index.theme` into an icon theme directory, for example:
`~/.local/share/icons/AETHER/`

Then select **AETHER** in the desktop appearance/icon theme settings. Exact integration depends on the desktop environment.

SVG files are resolution-independent. They can be rasterized to PNG at 16, 24, 32, 48, 64, 128, 256 or 512 px using standard SVG tooling.

## Important
This is an initial original icon asset pack, not a claim of official endorsement by any third party. Some complex brand-specific icons are deliberately represented with neutral generic symbols.
